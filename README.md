# IV&AX MOTO — дизайн-превью

[Посмотреть макет](https://manath-iq.github.io/moto-site/)

Статичный пример оформления для согласования. Не действующий магазин и не коммерческое предложение. Цены условные, изображения — визуализации. WhatsApp, административный вход и передача данных отключены.

Публичная сборка React/Vite; для переходов используется hash-навигация. Сервер, внутренний прайс, переписка и пароли сюда не включены.

Шрифты и значки поставляются со своими лицензиями в `licenses/`. Этот показ не предоставляет прав повторного использования бренда и изображений.
